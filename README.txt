OBSERVATION — Project Scheduler

실행 방법
1. 이 폴더를 그대로 유지합니다.
2. index.html을 더블클릭해 브라우저에서 엽니다.
3. + ADD SCHEDULE 버튼 또는 날짜 칸 더블클릭으로 일정을 추가합니다.

기능
- 월간 캘린더
- 이전/다음 달 이동
- 일정 추가 / 수정 / 삭제 (Delete/Backspace 키 및 원클릭 × 삭제 지원, 기간 일정 지원)
- 일정 드래그 앤 드롭으로 날짜 이동 (기간 유지)
- 카테고리, 포지션, 상태, 우선순위, 메모
- 카테고리 / 포지션 필터
- Calendar / Timeline 보기
- 브라우저 localStorage 자동 저장

중요
- 현재 버전은 같은 브라우저/기기에서만 일정이 저장됩니다.
- 여러 팀원이 같은 일정을 실시간 공유하려면 이후 Supabase/Firebase 같은 공용 DB 연결이 필요합니다.
