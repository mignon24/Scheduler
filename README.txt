OBSERVATION — Project Scheduler

접근 비밀번호 (권한 구분)
- 관리자 (나): qweryuiop — 모든 일정 추가, 수정, 삭제, 드래그 앤 드롭, 메모 편집 가능
- 구경용 (다른 사람들): 0000 — 읽기 전용 (일정 및 타임라인 조회만 가능, 수정/추가/삭제 불가)

실행 방법
1. index.html을 브라우저에서 엽니다.
2. 비밀번호 입력 창에 맞게 비밀번호를 입력합니다.
   - 나: qweryuiop 입력 -> ADMIN (수정 모드)
   - 다른 사람: 0000 입력 -> VIEW ONLY (구경 모드)
3. 상단 바에서 언제든지 '관리자 전환' 또는 '잠금'을 눌러 모드를 전환하거나 잠글 수 있습니다.

주요 기능
- 월간 캘린더 & 타임라인 보기
- 권한별 접근 제어 (관리자 모드 / 구경 모드)
- 관리자 모드:
  - + ADD SCHEDULE 및 날짜 더블클릭으로 새 일정 등록
  - 일정 드래그 앤 드롭 이동 (기간 유지)
  - 원클릭 삭제 (×) 및 Delete/Backspace 키보드 단축키 삭제
  - 우측 상단 메모 작성
- 구경 모드:
  - 일정 카드 클릭 시 읽기 전용 상세 보기 제공
  - 수정/삭제/추가/드래그 버튼 및 동작 전면 차단
- 브라우저 자동 세션 유지 (새로고침해도 권한 유지, 잠금 클릭 시 재인증)
